# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Use GitHub's private
vulnerability reporting ("Security" tab -> "Report a vulnerability") for this repository, and
include the affected version, steps to reproduce and the expected impact.

## Supported versions

Only the latest release receives security fixes.

## Deployment guidance

See the *Security* and *Hardening checklist* sections in the [README](README.md) and the
[security review](docs/SECURITY_REVIEW.md).
